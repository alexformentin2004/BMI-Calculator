# BodyTrack 1.0

PWA mobile-first per BMI, composizione corporea stimata (metodo US Navy), grafici e archivio del percorso.

## Uso

1. Apri GitHub Pages su iPhone con Safari, poi **Condividi → Aggiungi alla schermata Home**.
2. Imposta altezza e sesso nelle impostazioni.
3. Registra peso, circonferenza addome e collo (e fianchi per donne).
4. Consulta Home, Statistiche e Archivio.
5. Esporta periodicamente un backup JSON dal tuo archivio.

## Attivare GitHub Pages

Repository → Settings → Pages → Deploy from a branch → main → /(root) → Save.

I dati sono memorizzati solo nel browser via localStorage: se cancelli i dati del sito perderai lo storico non esportato. La repository pubblica non contiene misurazioni personali.

Le percentuali di massa grassa e massa magra sono stime antropometriche, non esami diagnostici. La massa magra non indica esclusivamente muscoli.
